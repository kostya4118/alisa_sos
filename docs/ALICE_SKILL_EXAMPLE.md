# Пример настройки навыка Алисы

Образец заполнения формы навыка в [Яндекс Диалогах](https://dialogs.yandex.ru/developer)
(**«Создать диалог» → «Навык в Алисе»**) для сервиса Alisa SOS. Копируйте значения
поле за полем; свой персональный **Webhook URL** возьмите из сообщения бота (кнопка
**📊 Статус**).

---

## Раздел «О навыке»

| Поле | Значение | Примечание |
|---|---|---|
| **Название навыка** | `СОС помощь друзей` | Отображается в каталоге; им же активируется навык |
| **Активационные имена** | `СОС помощь друзей` | ⚠️ Используйте слова, а не «С О С» по буквам — аббревиатуру Алиса распознаёт плохо. Можно добавить второй вариант, например `сос помощник` |
| **Примеры запросов** | `Открой СОС помощь друзей` | Только примеры для каталога, не команды |
| **Описание** | `Навык экстренного оповещения: одной голосовой командой рассылает SOS-сообщение близким в Telegram и MAX. Можно выбрать, кому отправить — всем или одному, и добавить голосом, что случилось.` | Текст для каталога |
| **Голос** | любой | На ваш вкус |

---

## Раздел «Backend» (главное)

| Поле | Значение |
|---|---|
| **Тип** | ✅ **Webhook URL** (НЕ «Функция в Яндекс Облаке») |
| **Webhook URL** | `https://<ваш-домен>/alice/<ваш-токен>` |

Пример полного адреса:

```
https://sos.ваш-домен.ру/alice/1da5f5ba-3186-44ef-b191-672db63faf12
```

⚠️ **Токен — полный UUID из 36 символов.** Вставьте строку из сообщения бота целиком,
не теряя последние символы, иначе Алиса вернёт 404 «Неизвестный токен».

Требования к адресу:
- только **HTTPS** с валидным сертификатом;
- доступен из интернета (`curl https://<ваш-домен>/health` → `{"status":"ok"}`);
- без слэша в конце, токен — последний сегмент пути.

---

## Раздел «Доступ»

| Поле | Значение | Почему так |
|---|---|---|
| **Тип доступа** | ✅ **Приватный** | Для личного SOS — оптимально: **модерация не нужна**, навык сразу работает на вашем аккаунте на колонке и в приложении Алисы. Публичным делайте, только если навыком будут пользоваться посторонние |

---

## Прочие поля

| Поле | Значение |
|---|---|
| **Категория** | `Общение` (подойдёт и `Здоровье и фитнес`) |
| **Возрастные ограничения** | 6+ (галочку 18+ не ставить) |
| **Хранилище данных** | ❌ Не использовать (состояние диалога бот держит сам) |
| **Иконка** | PNG/JPEG 1024×500 — нужна только для публичного навыка |
| **Доступные поверхности** | По умолчанию (Станция, Приложение Яндекса и т.д.); экран не требуется |

---

## Проверка после сохранения

1. Нажмите **«Сохранить»**.
2. Вкладка **«Тестирование»** → скажите/напишите: **«открой СОС помощь друзей»**.
3. Навык ответит, например: *«Отправить SOS всем 3 контактам или одному?»*
4. Ответьте **«всем»** → **«всё»** — подписчики получат сообщение.

> Приватный навык работает у вас лично сразу после «Сохранить» — модерацию проходить не нужно.

## Пример голосового диалога

```
Вы:    «Алиса, открой СОС помощь друзей»
Алиса: «Отправить SOS всем 3 контактам или одному?»
Вы:    «Одному»
Алиса: «Кому? Назовите имя. Доступные: Мама, Петя, Маша»
Вы:    «Маме»
Алиса: «Отправить SOS контакту Мама?»
Вы:    «Да»
Алиса: «Хотите добавить сообщение? Скажите что передать или "всё".»
Вы:    «Застряла в лифте на работе»
Алиса: «SOS отправлен контакту Мама. Держитесь!»
```

## Если что-то не работает

| Симптом | Причина / решение |
|---|---|
| «Неизвестный токен» (404) | Webhook вставлен не полностью — скопируйте токен из бота (📊 Статус) целиком |
| «Навык не отвечает» / ошибка вебхука | Сервис не запущен или адрес недоступен — `curl …/health` |
| Алиса не запускает навык | Скажите активационное имя словами: «открой СОС помощь друзей» |
| Навык отвечает, но SOS не приходит | Список контактов пуст — добавьте подписчиков по ссылке для друзей |

---

Этот же пример бот присылает владельцу автоматически вместе с Webhook URL при регистрации.
