# Инструкция по развёртыванию Alisa SOS

Бот для экстренного оповещения: голосовая команда Яндекс Алисе → мгновенное сообщение в Telegram всем нужным людям.

---

## Что вам понадобится

| Что | Где взять | Стоимость |
|-----|-----------|-----------|
| Сервер с Ubuntu 22.04 | Timeweb, Beget, Selectel, VK Cloud | от 200 ₽/мес |
| Домен | reg.ru, nic.ru, 2domains.ru | от 200 ₽/год |
| Аккаунт Telegram | telegram.org | бесплатно |
| Аккаунт Яндекс | ya.ru | бесплатно |
| Колонка с Алисой | Яндекс Маркет | от 3000 ₽ |

> Колонка нужна только для голосового управления. Без неё бот работает через Telegram.

---

## Шаг 1 — Создать Telegram бота

1. Откройте Telegram, найдите **@BotFather**
2. Отправьте `/newbot`
3. Придумайте название, например: `Мой SOS бот`
4. Придумайте username (должен заканчиваться на `bot`), например: `masha_sos_bot`
5. BotFather пришлёт токен:
   ```
   1234567890:AABBCCDDEEFFaabbccddeeff1234567890
   ```
   **Сохраните его** — это `TELEGRAM_BOT_TOKEN`

---

## Шаг 2 — Узнать свой Telegram ID

1. Найдите в Telegram бота **@userinfobot**
2. Отправьте `/start`
3. Бот ответит: `Id: 123456789`

**Сохраните это число** — это `ADMIN_CHAT_ID`

## Шаг 3 — Подготовить сервер

### 3.1 Подключитесь к серверу по SSH

```bash
ssh root@IP_вашего_сервера
```

### 3.2 Обновите систему

```bash
apt update && apt upgrade -y
```

### 3.3 Установите Docker

```bash
curl -fsSL https://get.docker.com | sh
```

Проверьте что установился:

```bash
docker --version
docker compose version
```

Оба должны вернуть версию.

### 3.4 Установите Nginx и Certbot

```bash
apt install nginx certbot python3-certbot-nginx -y
```

## Шаг 4 — Настроить DNS

В панели управления вашим доменом добавьте A-запись:

| Поле | Значение |
|------|----------|
| Тип | A |
| Имя | `sos` (или любое другое) |
| IP | IP вашего сервера |
| TTL | 3600 |

Узнать IP сервера:

```bash
curl ifconfig.me
```

Проверить что DNS обновился (может занять до 60 минут):

```bash
dig sos.ваш-домен.ru +short
```

Когда вернёт IP вашего сервера — переходите дальше.

## Шаг 5 — Скачать и настроить бота

### 5.1 Скачайте код

```bash
cd ~
git clone https://github.com/kostya4118/alisa_sos
cd alisa_sos
git checkout claude/telegram-alice-emergency-bot-CxrfN
```

### 5.2 Создайте файл настроек

```bash
cp .env.example .env
nano .env
```

Заполните все поля:

```env
# Токен от @BotFather
TELEGRAM_BOT_TOKEN=1234567890:AABBCCDDEEFFaabbccddeeff1234567890

# Ваш Telegram ID (от @userinfobot)
ADMIN_CHAT_ID=123456789

# Ваше имя — будет отображаться в SOS-сообщениях
OWNER_NAME=Маша

# Текст сообщения тревоги
SOS_MESSAGE=🆘 ТРЕВОГА! Мне нужна помощь! Это автоматическое сообщение.

# Настройки сервера — не менять
HOST=0.0.0.0
PORT=8000

# Секретный ключ для защиты вебхука (придумайте любую строку без пробелов)
ALICE_SECRET=

# Часовой пояс (разница с UTC: Москва = 3, Екатеринбург = 5, Новосибирск = 7)
TZ_OFFSET=3

# Не менять
CONTACTS_FILE=contacts.json
```

Сохраните: `Ctrl+O` → Enter → `Ctrl+X`

### 5.3 Создайте файл контактов

```bash
echo '{"contacts": {}}' > contacts.json
```

## Шаг 6 — Запустить бота

```bash
docker compose up -d
```

Подождите 5–10 секунд и проверьте:

```bash
curl http://localhost:8000/health
```

Должно вернуть: `{"status":"ok"}`

Если не работает — смотрите логи:

```bash
docker compose logs
```

**Не переходите дальше, пока этот шаг не работает.**

---

## Шаг 7 — Настроить Nginx

### 7.1 Создайте конфигурацию

```bash
nano /etc/nginx/sites-available/sos
```

Вставьте (замените `sos.ваш-домен.ru` на свой поддомен):

```nginx
server {
    listen 80;
    server_name sos.ваш-домен.ru;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

`Ctrl+O` → Enter → `Ctrl+X`

### 7.2 Активируйте конфигурацию

```bash
ln -s /etc/nginx/sites-available/sos /etc/nginx/sites-enabled/
nginx -t
```

Если видите `syntax is ok` и `test is successful`:

```bash
systemctl reload nginx
```

### 7.3 Проверьте

```bash
curl http://sos.ваш-домен.ru/health
```

Должно вернуть: `{"status":"ok"}`

Финальная проверка:

```bash
curl https://sos.ваш-домен.ru/health
```

Должно вернуть: `{"status":"ok"}`

## Шаг 9 — Настроить навык в Яндекс Диалогах

1. Откройте **https://dialogs.yandex.ru/developer**
2. Нажмите **«Создать диалог»** → **«Навык в Алисе»**

### Вкладка «Настройки»

| Поле | Значение |
|------|----------|
| Название | СОС (или любое) |
| Активационное имя | `С О С` (через пробелы) |
| Язык | Русский |
| Описание краткое | Экстренное оповещение контактов |
| Описание полное | Навык отправляет SOS-сообщение в Telegram всем подписанным контактам |
| Категория | Здоровье и фитнес |
| Возрастной рейтинг | 6+ |

### Вкладка «Веб-сервис»

| Поле | Значение |
|------|----------|
| Webhook URL | `https://sos.ваш-домен.ru/alice` |

### Вкладка «Логотип»

Загрузите любое изображение минимум 192×192 пикселя (требование Яндекса).

### Отправка на модерацию

1. Перейдите во вкладку **«Тестирование»** и проверьте что навык отвечает
2. Нажмите **«На модерацию»**
3. В комментарии напишите:
   ```
   Навык не требует авторизации. Для тестирования скажите «да» чтобы 
   отправить SOS, затем добавьте сообщение или скажите «всё».
   ```

Модерация занимает 1–3 рабочих дня. До одобрения навык работает только в режиме тестирования на сайте.

## Шаг 10 — Добавить контакты

Каждый человек, который должен получать SOS-сообщения, должен:

1. Открыть Telegram и найти вашего бота по username
2. Отправить `/start`
3. Нажать **«✅ Подписаться на оповещения»**

Вы получите уведомление: `👤 Новый подписчик: Имя`

Ссылку на бота можно отправить друзьям напрямую:
```
https://t.me/ваш_bot_username
```

### Управление контактами (только для вас как владельца)

| Команда | Действие |
|---------|----------|
| `👥 Контакты` | Список всех подписчиков с кнопками удаления |
| `🆘 Тест SOS` | Отправить тестовое сообщение всем |
| `/sos` | Экстренный SOS без Алисы (с подтверждением) |
| `📊 Статус` | Информация о боте |

```bash

docker compose restart
```


### Обновить до новой версии

```bash
cd ~/alisa_sos
git pull origin claude/telegram-alice-emergency-bot-CxrfN

```

### Проверить что бот запустится после перезагрузки сервера

```bash
reboot
# после перезагрузки через 1–2 минуты:
curl https://sos.ваш-домен.ru/health
```

Параметр `restart: unless-stopped` в `docker-compose.yml` гарантирует автозапуск.

## Если что-то пошло не так

| Симптом | Проверьте |
|---------|-----------|
| `curl health` возвращает 502 | `docker compose logs` — бот не запущен |
| `curl health` зависает | DNS не настроен или Nginx не запущен |
| Алиса отвечает «ошибка вебхука» | Бот не запущен, или `ALICE_SECRET` не совпадает |
| Контакт не получил SOS | Написал ли он `/start` боту? Не заблокировал ли бота? |
| Docker не запускается | `systemctl start docker && systemctl enable docker` |
| Certbot не получает сертификат | DNS ещё не обновился, подождите и повторите |
| Бот падает сразу после запуска | `TELEGRAM_BOT_TOKEN` неверный или нет интернета из контейнера — добавьте `dns: [8.8.8.8]` в `docker-compose.yml` |
