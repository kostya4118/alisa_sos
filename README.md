# Alisa SOS

Сервис экстренного оповещения: голосовая команда Яндекс Алисе → мгновенные сообщения в Telegram всем нужным людям.

Работает как **мультиарендный** сервис: любой человек может зарегистрироваться в боте, получить собственный URL для навыка Алисы и свою ссылку для подписчиков — без пересечения с другими пользователями.

---

## Как это работает

```
Пользователь говорит Алисе:
«Алиса, открой навык С О С»
        │
        ▼
Яндекс Диалоги вызывают вебхук:
POST https://ваш-домен.ru/alice/{webhook_token}
        │
        ▼
Алиса уточняет детали
(кому отправить, добавить ли сообщение)
        │
        ▼
Бот рассылает SOS в Telegram
всем подписчикам владельца
        │
        ▼
Контакты могут ответить — Алиса
зачитает ответы при следующем открытии
и предложит написать им в ответ
```

### Диалог с Алисой

```
Вы:    «Алиса, открой навык С О С»
Алиса: «Есть 2 новых ответа от ваших контактов. Зачитать?»
Вы:    «Да»
Алиса: «Мама написал: еду к тебе. Петя написал: буду через 10 минут.
        Хотите ответить? Назовите имя или скажите пропустить. Писали: Мама, Петя.»
Вы:    «Маме»
Алиса: «Что передать Мама?»
Вы:    «Жду тебя, спасибо»
Алиса: «Ответ отправлен Мама. Отправить SOS всем 3 контактам или одному?»
Вы:    «Одному»
Алиса: «Кому? Назовите имя. Доступные: Мама, Петя, Маша»
Вы:    «Маше»
Алиса: «Отправить SOS контакту Маша Иванова?»
Вы:    «Да»
Алиса: «Хотите добавить сообщение?»
Вы:    «Я застряла в лифте»
Алиса: «SOS отправлен контакту Маша Иванова. Держитесь!»
```

## Возможности

### Экстренный SOS

- **Голосовой SOS** — достаточно сказать Алисе одну фразу
- **Выбор адресата** — всем сразу или конкретному человеку по имени
- **Дополнительное сообщение** — можно голосом уточнить, что случилось
- **SOS через бота** — кнопка «🚨 Отправить SOS» или команда `/sos` с подтверждением
- **Тест рассылки** — «🆘 Тест SOS» отправляет тестовое сообщение с пометкой

### Ответы контактов

- **Двусторонняя связь** — подписчик пишет боту любой текст, владелец получает уведомление немедленно
- **Алиса зачитывает ответы** — при открытии навыка: «Есть N новых ответов. Зачитать?»
- **Ответ голосом** — после зачтения Алиса предлагает ответить каждому контакту прямо через колонку
- **Проверка перед SOS** — перед каждым «Отправить SOS?» Алиса проверяет наличие новых ответов
- **Кнопка «📬 Ответы»** — просмотр непрочитанных ответов в Telegram

### Авточек (dead-man switch)

Необязательная функция. Если включена — бот ежедневно в указанное время спрашивает «Всё в порядке?».

```
09:00 — 👋 Ежедневная проверка. Всё в порядке?
          [✅ Всё хорошо]  [🆘 Нужна помощь]

  нет ответа 1 час →

10:00 — ⚠️ Вы не ответили час назад. Всё хорошо?

  нет ответа 30 минут →

10:30 — 🚨 Последняя проверка! Если не ответите 10 минут — SOS уйдёт автоматически.

  нет ответа 10 минут →

10:40 — 🆘 Авто-SOS разослан всем контактам
```

Любое текстовое сообщение боту также подтверждает проверку. Кнопка «🆘 Нужна помощь» отправляет SOS немедленно.

Настройка: `⚙️ Настройки → ⏰ Авточек`

### Управление

- **Кнопочный интерфейс** — все действия доступны через кнопки, команды помнить не нужно
- **Настройки через меню** — имя, текст SOS, часовой пояс — редактируются кнопками без команд
- **Мультиарендность** — каждый пользователь изолирован, данные не смешиваются
- **Часовой пояс** — время в SOS-сообщениях и авточеке показывается в вашем часовом поясе
- **Ссылка-приглашение** — подписчики добавляются одним нажатием по личной ссылке

```
┌──────────────────────────────────────────────────────┐
│  main.py  — точка входа, запускает три задачи        │
├─────────────────┬────────────────┬───────────────────┤
│   bot.py        │   alice.py     │   checkin.py      │
│   Telegram-бот  │   FastAPI      │   Фоновый цикл    │
│   (aiogram 3)   │   /alice/{tok} │   авточека (60 с) │
├─────────────────┴────────────────┴───────────────────┤
│  notifier.py — рассылка SOS через Telegram API       │
├──────────────────────────────────────────────────────┤
│  db.py — SQLite через aiosqlite                      │
│  migrate.py — импорт данных из старой версии         │
│  config.py — настройки через переменные окружения    │
└──────────────────────────────────────────────────────┘
```

**Стек:** Python 3.12, FastAPI, uvicorn, aiogram 3, SQLite, aiosqlite, Docker.

### Схема базы данных

```sql
owners    — зарегистрированные пользователи (владельцы навыка)
contacts  — подписчики каждого владельца
replies   — ответы подписчиков на SOS-сообщения
checkins  — настройки и состояние авточека каждого владельца
```

## Быстрый старт для нового пользователя

Если сервис уже развёрнут — никакой установки не нужно.

### 1. Зарегистрируйтесь как владелец

Найдите бота в Telegram и отправьте `/register`. Бот пришлёт:
- **Webhook URL** — вставьте в настройки навыка Яндекс Диалогов
- **Ссылку для друзей** — поделитесь с теми, кто должен получать SOS

### 2. Добавьте подписчиков

Отправьте друзьям ссылку вида:
```
https://t.me/ваш_бот?start=sub_xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```
Они нажимают «Старт» → автоматически подписываются. Вы получаете уведомление.

### 3. Настройте навык Алисы

1. Зайдите на [dialogs.yandex.ru/developer](https://dialogs.yandex.ru/developer)
2. Создайте навык → укажите **активационное имя** `С О С` (через пробелы)
3. В поле **Webhook URL** вставьте ссылку, которую прислал бот
4. Отправьте на модерацию (1–3 рабочих дня)

До одобрения модерацией навык работает в режиме тестирования прямо на сайте.

### 4. Протестируйте

Нажмите **🆘 Тест SOS** — подписчики получат тестовое сообщение. В Яндекс Диалогах используйте встроенный симулятор.

### 5. (Опционально) Включите авточек

`⚙️ Настройки → ⏰ Авточек → Включить` → введите время, например `09:00`.

## Кнопки и команды бота

### Клавиатура владельца

```
┌──────────────────┬──────────────────┐
│  👥 Контакты     │  🆘 Тест SOS     │
├──────────────────┼──────────────────┤
│  📬 Ответы       │  🚨 Отправить SOS│
├──────────────────┼──────────────────┤
│  🔗 Ссылка       │  📊 Статус       │
├──────────────────┴──────────────────┤
│          ⚙️ Настройки               │
└─────────────────────────────────────┘
```

### Меню настроек (⚙️)

```
✏️ Изменить имя
📝 Изменить текст SOS
🕐 Изменить часовой пояс
⏰ Авточек
🗑 Удалить аккаунт
```

Каждый пункт запрашивает ввод и предлагает кнопку «❌ Отмена». Для отмены также работает `/cancel`.

### Полная таблица команд

#### Владелец

| Кнопка / команда | Действие |
|---|---|
| `/register` | Зарегистрироваться, получить Webhook URL и ссылку для друзей |
| `📊 Статус` / `/settings` | Показать все настройки, webhook, ссылку |
| `⚙️ Настройки` | Меню редактирования (имя, текст SOS, часовой пояс, авточек, удалить) |
| `👥 Контакты` | Список подписчиков с кнопками удаления каждого |
| `🆘 Тест SOS` | Разослать тестовый SOS всем (пометка «не паникуйте!») |
| `🚨 Отправить SOS` / `/sos` | Разослать настоящий SOS (с подтверждением) |
| `📬 Ответы` / `/replies` | Просмотреть непрочитанные ответы от контактов |
| `🔗 Ссылка для друзей` | Получить персональную ссылку для подписки |
| `/setname Имя` | Изменить имя (альтернатива меню) |
| `/setmessage Текст` | Изменить текст SOS (альтернатива меню) |
| `/settz 3` | Установить часовой пояс (альтернатива меню) |
| `/cancel` | Отменить ожидаемый ввод (имя, текст и т.д.) |
| `/deleteaccount` | Удалить аккаунт и всех подписчиков |

#### Подписчик

| Кнопка / команда | Действие |
|---|---|
| Ссылка `?start=sub_...` | Подписаться на оповещения |
| `📋 Мои подписки` | Показать список владельцев |
| `❌ Отписаться` / `/unsubscribe` | Отписаться от всех оповещений |
| Любой текст | Переслать владельцу как ответ (Алиса зачитает вслух) |

## Функция ответов

1. Владелец через Алису отправляет SOS
2. Подписчик получает сообщение в Telegram и пишет боту любой текст
3. Бот немедленно пересылает ответ владельцу: `💬 Ответ от Имя: текст`
4. При следующем открытии навыка Алиса говорит: *«Есть N новых ответов. Зачитать?»*
5. Владелец говорит «да» → Алиса зачитывает все ответы по очереди
6. Алиса предлагает ответить каждому контакту голосом прямо через колонку
7. После ответов (или «пропустить») → проверяет наличие новых ответов → SOS-сценарий

## Авточек (dead-man switch)

Необязательная функция, отключена по умолчанию.

**Включение:** `⚙️ Настройки → ⏰ Авточек → Включить → ввести время`

**Логика:**

| Время | Событие |
|---|---|
| T + 0 | Бот отправляет «👋 Всё в порядке?» с кнопками |
| T + 1 ч | Повтор: «⚠️ Вы не ответили час назад» |
| T + 1 ч 30 мин | Финал: «🚨 Последняя проверка, 10 минут до SOS» |
| T + 1 ч 40 мин | Автоматический SOS всем контактам |

**Подтверждение** (любое из):
- Кнопка «✅ Всё хорошо» в сообщении проверки
- Кнопка «🆘 Нужна помощь» → немедленный SOS
- Любой текст боту в период проверки

## Настройка окружения

Файл `.env` (скопировать из `.env.example`):

```env
# Токен Telegram-бота от @BotFather
TELEGRAM_BOT_TOKEN=1234567890:AABBCCDDEEFFaabbccddeeff1234567890

# Публичный URL сервиса (без слэша в конце)
BASE_URL=https://sos.ваш-домен.ru

# Адрес и порт для uvicorn
HOST=0.0.0.0
PORT=8000

# Путь к файлу базы данных
DB_PATH=data/sos.db

# --- Только для миграции из старой версии ---
# ADMIN_CHAT_ID=123456789
# OWNER_NAME=Маша
# SOS_MESSAGE=🆘 ТРЕВОГА! Мне нужна помощь!
# TZ_OFFSET=3
# CONTACTS_FILE=contacts.json
```

| Переменная | Обязательная | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Да | Токен от @BotFather |
| `BASE_URL` | Да | Публичный HTTPS-адрес сервиса |
| `HOST` | Нет | Адрес для прослушивания (по умолчанию `0.0.0.0`) |
| `PORT` | Нет | Порт (по умолчанию `8000`) |
| `DB_PATH` | Нет | Путь к SQLite-файлу (по умолчанию `sos.db`) |
| `ADMIN_CHAT_ID` | Нет | Только для миграции из старой версии |

## Развёртывание

Подробная инструкция по шагам — в [DEPLOY.md](DEPLOY.md).

### Краткая инструкция (Docker)

```bash
# Клонировать репозиторий
git clone https://github.com/kostya4118/alisa_sos
cd alisa_sos

# Создать файл настроек
cp .env.example .env
nano .env   # заполнить TELEGRAM_BOT_TOKEN и BASE_URL

# Создать папку для данных и запустить
mkdir -p data
docker compose up -d

# Проверить
curl http://localhost:8000/health
# {"status":"ok"}
```

### Nginx (reverse proxy)

```nginx
server {
    listen 80;
    server_name sos.ваш-домен.ru;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

После настройки Nginx — получить SSL через Certbot:

```bash
certbot --nginx -d sos.ваш-домен.ru
```

### Обновление

```bash
git pull origin feature/multi-tenant
docker compose up -d --build
```

## Миграция из старой (однопользовательской) версии

Если в `.env` есть `ADMIN_CHAT_ID` — при первом запуске бот автоматически:
1. Создаёт запись владельца из переменных `OWNER_NAME`, `SOS_MESSAGE`, `TZ_OFFSET`
2. Импортирует контакты из `contacts.json`
3. Выводит в лог новый Webhook URL, который нужно вставить в Яндекс Диалоги

Миграция идемпотентна — повторный запуск ничего не делает.

```
migrate: created owner 123456789 (Маша)
migrate: contact Петя (987654321)
migrate: NEW WEBHOOK URL → https://sos.домен.ru/alice/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
migrate: Update this URL in your Yandex Dialogs skill settings!
```
