# Alisa SOS

Сервис экстренного оповещения: голосовая команда Яндекс Алисе → мгновенные сообщения в Telegram всем нужным людям.

Работает как **мультиарендный** сервис: любой человек может зарегистрироваться в боте, получить собственный URL для навыка Алисы и свою ссылку для подписчиков — без пересечения с другими пользователями.

---

## Как это работает

```
Пользователь говорит Алисе:
«Алиса, открой навык С О С»
        │
        ▼
Яндекс Диалоги вызывают вебхук:
POST https://ваш-домен.ru/alice/{webhook_token}
        │
        ▼
Алиса уточняет детали
(кому отправить, добавить ли сообщение)
        │
        ▼
Бот рассылает сообщение в Telegram
всем подписчикам владельца
        │
        ▼
Если контакты отвечают — Алиса
зачитает ответы при следующем открытии навыка
```

### Диалог с Алисой

```
Вы:    «Алиса, открой навык С О С»
Алиса: «Есть 2 новых ответа от ваших контактов. Зачитать?»
Вы:    «Да»
Алиса: «Мама написала: еду к тебе. Петя написал: буду через 10 минут.
        Отправить SOS всем 3 контактам или одному?»
Вы:    «Одному»
Алиса: «Кому? Назовите имя. Доступные: Мама, Петя, Маша»
Вы:    «Маше»
Алиса: «Отправить SOS контакту Маша Иванова?»
Вы:    «Да»
Алиса: «Хотите добавить сообщение?»
Вы:    «Я застряла в лифте»
Алиса: «SOS отправлен контакту Маша Иванова. Держитесь!»
```

## Возможности

- **Голосовой SOS** — достаточно сказать Алисе одну фразу
- **Выбор адресата** — всем сразу или конкретному человеку по имени
- **Дополнительное сообщение** — можно голосом уточнить, что случилось
- **Ответы контактов** — подписчики отвечают через Telegram, Алиса зачитывает ответы вслух
- **Тест через бота** — проверить рассылку без Алисы
- **Часовой пояс** — время в SOS-сообщении показывается в вашем часовом поясе
- **Мультиарендность** — каждый пользователь изолирован, данные не смешиваются

## Архитектура

```
┌─────────────────────────────────────────────────┐
│  main.py  — точка входа, запускает оба сервиса  │
├────────────────────┬────────────────────────────┤
│   bot.py           │   alice.py                 │
│   Telegram бот     │   FastAPI вебхук           │
│   (aiogram 3.x)    │   POST /alice/{token}      │
├────────────────────┴────────────────────────────┤
│  notifier.py — рассылка SOS через Telegram API  │
├─────────────────────────────────────────────────┤
│  db.py — SQLite через aiosqlite                 │
│  migrate.py — импорт данных из старой версии    │
│  config.py — настройки через переменные окружения│
└─────────────────────────────────────────────────┘
```

**Стек:** Python 3.12, FastAPI, uvicorn, aiogram 3, SQLite, aiosqlite, Docker.

### Схема базы данных

```sql
owners    — зарегистрированные пользователи (владельцы навыка)
contacts  — подписчики каждого владельца
replies   — ответы подписчиков на SOS-сообщения
```

## Быстрый старт для нового пользователя

Если сервис уже развёрнут — никакой установки не нужно.

### 1. Зарегистрируйтесь как владелец

Найдите бота в Telegram и отправьте `/register`. Бот пришлёт:
- **Webhook URL** — вставьте в настройки навыка Яндекс Диалогов
- **Ссылку для друзей** — поделитесь с теми, кто должен получать SOS

### 2. Добавьте подписчиков

Отправьте друзьям ссылку вида:
```
https://t.me/ваш_бот?start=sub_xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```
Они нажимают «Старт» → автоматически подписываются. Вы получаете уведомление.

### 3. Настройте навык Алисы

1. Зайдите на [dialogs.yandex.ru/developer](https://dialogs.yandex.ru/developer)
2. Создайте навык → укажите **активационное имя** `С О С` (через пробелы)
3. В поле **Webhook URL** вставьте ссылку, которую прислал бот
4. Отправьте на модерацию (1–3 рабочих дня)

До одобрения модерацией навык работает в режиме тестирования прямо на сайте.

### 4. Протестируйте

В Telegram нажмите **🆘 Тест SOS** — подписчики получат тестовое сообщение. В Яндекс Диалогах используйте встроенный симулятор.

## Команды бота

### Владелец

| Команда / кнопка | Действие |
|---|---|
| `/register` | Зарегистрироваться, получить Webhook URL и ссылку для друзей |
| `/settings` или `📊 Статус` | Показать все настройки, статистику, ссылки |
| `👥 Контакты` | Список подписчиков с кнопками удаления |
| `🆘 Тест SOS` | Отправить тестовый SOS всем подписчикам |
| `/sos` | Отправить реальный SOS (с подтверждением) |
| `🔗 Ссылка для друзей` | Получить ссылку для подписки |
| `/setname Имя` | Изменить имя, отображаемое в SOS-сообщениях |
| `/setmessage Текст` | Изменить текст SOS-сообщения |
| `/settz 3` | Установить часовой пояс (число от −12 до +14) |
| `/replies` | Просмотреть непрочитанные ответы от контактов |
| `/deleteaccount` | Удалить аккаунт и всех подписчиков |

### Подписчик

| Команда / кнопка | Действие |
|---|---|
| Ссылка `?start=sub_...` | Подписаться на оповещения владельца |
| `📋 Мои подписки` | Показать список владельцев, на которых подписан |
| Любое текстовое сообщение | Переслать владельцу как ответ (Алиса зачитает вслух) |
| `/unsubscribe` | Отписаться от всех оповещений |

---

## Функция ответов

Подписчик получил SOS-сообщение и хочет ответить — он просто пишет боту текст. Бот:
1. Сохраняет ответ в базе данных
2. Пересылает его владельцу в Telegram немедленно
3. При следующем открытии навыка Алиса сообщает: *«Есть N новых ответов. Зачитать?»*

Если владелец говорит «да» — Алиса зачитывает все ответы по очереди, затем переходит к стандартному SOS-сценарию. Команда `/replies` в боте показывает то же самое в текстовом виде.

## Настройка окружения

Файл `.env` (скопировать из `.env.example`):

```env
# Токен Telegram-бота от @BotFather
TELEGRAM_BOT_TOKEN=1234567890:AABBCCDDEEFFaabbccddeeff1234567890

# Публичный URL сервиса (без слэша в конце)
BASE_URL=https://sos.ваш-домен.ru

# Адрес и порт для uvicorn
HOST=0.0.0.0
PORT=8000

# Путь к файлу базы данных
DB_PATH=data/sos.db

# --- Только для миграции из старой версии ---
# ADMIN_CHAT_ID=123456789
# OWNER_NAME=Маша
# SOS_MESSAGE=🆘 ТРЕВОГА! Мне нужна помощь!
# TZ_OFFSET=3
# CONTACTS_FILE=contacts.json
```

| Переменная | Обязательная | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Да | Токен от @BotFather |
| `BASE_URL` | Да | Публичный HTTPS-адрес сервиса |
| `HOST` | Нет | Адрес для прослушивания (по умолчанию `0.0.0.0`) |
| `PORT` | Нет | Порт (по умолчанию `8000`) |
| `DB_PATH` | Нет | Путь к SQLite-файлу (по умолчанию `sos.db`) |
| `ADMIN_CHAT_ID` | Нет | Только для миграции из старой версии |

## Развёртывание

Подробная инструкция по шагам — в [DEPLOY.md](DEPLOY.md).

### Краткая инструкция (Docker)

```bash
# Клонировать репозиторий
git clone https://github.com/kostya4118/alisa_sos
cd alisa_sos

# Создать файл настроек
cp .env.example .env
nano .env   # заполнить TELEGRAM_BOT_TOKEN и BASE_URL

# Создать папку для данных и запустить
mkdir -p data
docker compose up -d

# Проверить
curl http://localhost:8000/health
# {"status":"ok"}
```

### Nginx (reverse proxy)

```nginx
server {
    listen 80;
    server_name sos.ваш-домен.ru;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

После настройки Nginx — получить SSL через Certbot:

```bash
certbot --nginx -d sos.ваш-домен.ru
```

### Обновление

```bash
git pull
docker compose up -d --build
```

## Миграция из старой (однопользовательской) версии

Если в `.env` есть `ADMIN_CHAT_ID` — при первом запуске бот автоматически:
1. Создаёт запись владельца из переменных `OWNER_NAME`, `SOS_MESSAGE`, `TZ_OFFSET`
2. Импортирует контакты из `contacts.json`
3. Выводит в лог новый Webhook URL, который нужно вставить в Яндекс Диалоги

Миграция идемпотентна — повторный запуск ничего не делает. Старые переменные окружения можно оставить или удалить.

```
migrate: created owner 123456789 (Маша)
migrate: contact Петя (987654321)
migrate: NEW WEBHOOK URL → https://sos.домен.ru/alice/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
migrate: Update this URL in your Yandex Dialogs skill settings!
```

## Локальная разработка

```bash
# Установить зависимости
pip install -r requirements.txt

# Создать .env с минимальными настройками
TELEGRAM_BOT_TOKEN=...
BASE_URL=http://localhost:8000
DB_PATH=data/sos.db

# Запустить
python main.py
```

Для тестирования вебхука Алисы локально удобно использовать [ngrok](https://ngrok.com/):

```bash
ngrok http 8000
# Скопировать HTTPS-адрес в BASE_URL и в настройки навыка
```
